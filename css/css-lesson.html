بسم الله الرحمن الرحيم

في هذا الموقع ستتعلم CSS بطريقة تفاعلية ومبسطة، من الصفر حتى الاحتراف.

العودة إلى درس HTML

في CSS، يمكنك كتابة الأكواد بثلاث اماكن مختلفة:

  1. داخل العنصر (Inline)
  2. داخل <head>ـ (Internal)
  3. في ملف منفصل (External)

1. المكان الأول: داخل العنصر (Inline)

في هذه الطريقة، يمكنك كتابة الأكواد مباشرة داخل العنصر باستخدام الخاصية style. على سبيل المثال:

<p style="color: red; font-size: 20px;"> هنا نص أحمر بحجم 20px </p>

في هذا المثال، قمنا بتغيير لون النص إلى الأحمر وحجمه إلى 20px باستخدام الخاصية style داخل العنصر <p>.

2. المكان الثاني: داخل <head>ـ (Internal)

في هذه الطريقة، يمكنك كتابة الأكواد داخل وسم <style> في قسم <head> من الصفحة. على سبيل المثال:

<head>
    <style>
        p {
            color: blue;
            font-size: 18px;
        }
    </style>
</head>

في هذا المثال، قمنا بتغيير لون جميع العناصر <p> إلى الأزرق وحجمها إلى 18px باستخدام وسم <style> داخل <head>.

3. المكان الثالث: في ملف منفصل (External)

في هذه الطريقة، يمكنك كتابة الأكواد في ملف CSS منفصل وربطه بالصفحة باستخدام وسم <link>. على سبيل المثال:

<head>
    <link rel="stylesheet" href="styles.css">
    </head>

في هذا المثال، قمنا بربط ملف CSS خارجي باسم styles.css بالصفحة باستخدام وسم <link> داخل <head>. يمكنك كتابة جميع الأكواد في هذا الملف وتطبيقها على الصفحة.

ملاحظة: في ملف .css، تكتب الأكواد مباشرة بدون style.

الخلاصة

يمكنك استخدام أي من الطرق الثلاثة لكتابة أكواد CSS حسب احتياجاتك وتفضيلاتك. المكان الأول مناسب للتغييرات السريعة والمحدودة، بينما المكان الثاني والثالث مناسبان للمشاريع الكبيرة والمعقدة حيث يمكنك تنظيم الأكواد بشكل أفضل.

اماكن كتابة كلمة style

كلمة style تكتب اذا تريد ان تغير عنصر في html ولها ثلاث مواضع او اماكن ويختلف كل مكان عن الاخر حسب ما تريد.

المكان اين تستخدم؟ لماذا؟
Inline داخل العنصر لأنك تكتب CSS مباشرة داخل العنصر، فتحتاج الخاصية style عشان تحدد التنسيق.
Internal داخل <head> لأنك تكتب CSS داخل وسم <style> في <head>.
External في ملف منفصل لأنك تربط ملف CSS خارجي باستخدام <link>، وما تحتاج style نهائياً.

الخلاصة: اذا كنت ترغب ان تستخدم كلمة style فإنها تكتب في الماكنين الأول والثاني، اما المكان الثالث فـ style ما لها دخل فيها.

تركيب CSS (Syntax)

أي كود في CSS يتكون من ثلاثة أجزاء رئيسية:

  1. المحدد (Selector): تحدد العنصر اللي تبي تغير شكله (مثل h1، p، body).
  2. الخاصية (Property): تحدد وش تبي تغير في العنصر (مثل color، font-size، text-align).
  3. القيمة (Value): تحدد القيمة الجديدة للخاصية (مثل red، 20px، center).

مثال توضيحي:

h1 {
    text-align: center;
}
  • المحدد: h1 (يستهدف جميع عناوين h1)
  • الخاصية: text-align (تتحكم في محاذاة النص)
  • القيمة: center (توسيط النص)

ملاحظة: كل جزء له دور محدد، وبهالطريقة تقدر تتحكم في شكل أي عنصر في الصفحة.

المحددات في CSS

المحددات هي الطريقة اللي تحدد فيها العنصر اللي تبي تغير شكله في CSS.

في CSS، فيه أنواع مختلفة من المحددات، وكل نوع له استخدام معين:

  1. محدد العنصر: يغير كل العناصر من نفس النوع، مثل كل الفقرات أو كل العناوين. يكتب بدون أي علامة، فقط اسم العنصر. مثال: p.
  2. محدد الفئة (Class): يغير العناصر اللي تحمل نفس الكلاس. تكتب النقطة . قبل اسم الكلاس. مثال: .title.
  3. محدد المعرف (Id): يغير عنصر واحد فقط، لأن المعرف يكون فريد في الصفحة. تكتب العلامة # قبل اسم المعرف. مثال: #header.
  4. المحدد العام (Universal): يطبق التنسيق على كل العناصر في الصفحة. يكتب باستخدام العلامة *. مثال: *.

ملاحظة: المحدد العام مفيد للتنسيقات العامة، لكن استخدمه بحذر لأنه يطبق على كل شيء.
